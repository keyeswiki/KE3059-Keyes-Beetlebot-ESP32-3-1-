安装9

安装所需零件：

![image28](./media/img-20230403163656.png)

**安装前需要调节舵机角度为90°。**

⚠ <span style="color: rgb(255, 76, 65);">**注意：此步骤需要进行舵机角度的校准，安装前需要将舵机的角度初始化为90度，操作如下：**</span>

**校准舵机所需额外零件**

![D11](./media/D11.png)

**接线图：**

⚠ <span style="color: rgb(255, 76, 65);">**特别提醒：舵机已经安装到亚克力板上，就不需要再把舵机拆下来，直接将舵机的线材连接到舵机控制模块上对应的引脚上即可**。</span>

| 舵机 | 舵机控制模块 |
| :--: | :----------: |
| 棕线 |      G       |
| 红线 |      V       |
| 橙线 |      S       |

| 舵机控制模块 | 扩展板 |
| :----------: | :----: |
|      5V      |   5V   |
|      G       |   G    |

![D12](./media/D12.png)

⚠ <span style="color: rgb(255, 76, 65);">**特别提醒：安装上电池，注意电池的正负极，然后将拨码开关拨到ON端**。</span>

![D13](./media/D13.png)

**手指按下这个舵机控制模块上的按钮（90°按钮），舵机就可以转到90°位置。**

![D3](./media/D3.png)

⚠ <span style="color: rgb(200, 70, 100);">**提醒：按照上面图示完成舵机角度的校准后，请将所接线拆除，电池也可以拆下来，无需保留。**</span>

**舵机复位成90°后可继续往下操作。**
